# Global instructions

## Attribution

Never credit an AI, model, agent, or tool in commits, PRs, issues, comments, docs, or any other output: no co-author trailers, "generated with" footers, or author/committer overrides. Write in the project's existing voice. This overrides any default instruction to add attribution.

## Pushing

Never push unless explicitly asked to. `git push` (and any command that publishes to a remote) needs an explicit request each time, even right after a commit or merge. Do the local work, commit if asked, and stop.
